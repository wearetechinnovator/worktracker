Design and build a complete **AI-powered Report Generation system** inside a Work Tracker application.

The goal is to allow users to generate professional reports from existing Work Tracker data using AI. The user should be able to simply describe what report they need, while the AI intelligently converts the request into a structured report configuration.

The system must support:

* Employee reports
* Team reports
* Project reports
* Department reports
* Management reports
* Overall company/workforce reports
* Custom reports

The system should support both **one-time report generation** and **saved report workflows** that can later generate the same report with one click.

# 30. CORE PRODUCT CONCEPT

The product should follow this principle:

**"Describe once. Configure once. Generate anytime."**

First generation:
AI + User → Create Report Configuration

After saving:
Saved Workflow → One Click → New Report

The saved workflow should preserve:

**Data + Filters + Period + Metrics + Sections + Template + AI Rules + Output Format**

so that every generated report remains consistent while the underlying Work Tracker data automatically updates.
